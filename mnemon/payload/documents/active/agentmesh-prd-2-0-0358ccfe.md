# AgentMesh PRD 2.0 收敛

> 来源：工作区 D:\ZISHIKU\AI\AgentMesh 的 `AgentMesh.md`（PRD，收敛后约 703 行 / 37 KB）。前身记录见文档 605ea0f0-be14-4bef-be49-82b653c9a8ef（PRD 1.1 功能补强层）与 d373d32b-0b73-4671-8066-ccf944a194b2（一期设计定稿）；本文只记录 2.0 收敛的裁决与理由，不复制全文。

## 1. 用户目标（唯一口径，贯穿全文）

**让用户自定义多个 Agent 与应用程序之间的通讯；系统只承载与路由，不做预设编排。**
配套约束：单机本地、只有一期（真实 CLI 与真实 GUI 都在本期接入，不设二期）、Agent / 应用的原生能力全部保留。

## 2. 触发与裁决过程

1. **用户首先要求**：功能设计不要冗余，记住目标是什么。当时 PRD 1.1 有 771 行、16 组功能需求（FR-1~FR-16），而"目标 → 能力 → 需求编号"映射表只有 6 行，多出的 5 组在目标里找不到对应项。
2. **收敛原则**：按目标倒推——每一行需求都必须是"不做它，用户就退回单干"的能力，表外一律不做。
3. **用户追问**：删减后"有没有为了项目功能方便好用而需要做的"。复核承认上一轮只按条目名判断、没按流程判断，于是按"派活 → 互相找 → 看进度 → 失败重来 → 换人接手"逐环节复核，恢复两项。
4. **结论**：恢复时只新增条目、不新增整数编号的需求组（保持 11 组），避免重新膨胀。

## 5. 保留的两项复核恢复（用户追问"为好用而该做"）

| 被删项 | 用户会不会卡住 | 处理 |
|---|---|---|
| 共享上下文 | 会：记录能查，但接手的人不知道"现在做到哪、下一步干嘛"，用户得自己复述 | 恢复为**任务上的交接摘要**字段（FR-11.6），不另建模块 |
| 误派 / 误发给全组 | 会：只能将错就错，成员白干 | 恢复为**派活后 10 秒内可撤回**（FR-10.6） |
| 取消进行中的 request | Agent 不配合就不可靠 | 不恢复，0.2 写明原因 |
| 模板导入导出、资源与并发边界、附录 D、协议调研 | — | 不恢复（用不上 / 属实现质量 / 与 0.1 重复） |

## 6. 2.0 最终范围（11 组功能需求）

FR-1 节点管理、FR-2 Group、FR-3 Spawn、FR-4 消息与请求（send / request）、FR-5 Trace 与重试（含记录可查，原 FR-12 并入）、FR-6 UI、FR-7 Herdr 集成（独立 sidecar，socket API 管 pane）、FR-8 应用 / Agent 接入（CLI 走 MCP、GUI 走 WS，不改原生能力）、FR-9 持久化与 GC（SQLite / WAL、保留 30 天可配置）、FR-10 派活入口（FR-10.1 输入框、10.2 小组/个人路由、10.3 等结果不阻塞、10.4 沿用上次设置、10.5 记录回看、10.6 10 秒内撤回）、FR-11 任务看板（FR-11.1 进行中/等待/完成/失败、11.2 负责人+当前步骤+最后消息时间、11.3 子代理挂任务、11.4 关闭/重开、11.5 任务↔消息链双向跳转、11.6 交接摘要）。

关键决策（附录 A）：D1 三种固定模式 + 组队/派生/私聊，不做规则引擎；D2 GUI 只做接入不启动不嵌窗；D3 Herdr 独立 sidecar；D4 完整 Spawn 树一树一 trace、子节点只允许 CLI；D5 send 单向 / request 请求-应答；D6 只有一期；D7 不替换原生能力；D8 单一 PRD 文档；D9 界面一句话派活不做流程编排；D10 看板只读派生自任务与消息，不引入第二套状态；D11 共享只读不改写原生会话；D12 失败只重发消息不重跑 Agent，旁支保留；D13 商业能力另起文档。

## 7. 验收与发布门槛

- 基础验收 A1-A12；功能验收 F1-F8（F1 一句话派活、F2 小组/个人路由正确、F3 等结果不阻塞、F4 看板显示负责人/步骤/时间/失败原因、F5 任务可点开看消息链与产物、F6 一键重来且旁支保留、F7 10 秒内撤回、F8 新成员看得到交接摘要）。
- 第一波发布门槛须同时满足才允许对外说"比单干强"：能派活（F1、F2、F3、A8）→ 能看到进度（F4、F5、A6、A7）→ 能重来（F6、A9）。
- 数据：Task 增加 `handoff_summary` 字段。

## 8. 下一步

对照第一波四件事推进：接通真实收发（取代 mock 的 MCP/WS 适配器）→ 派活（含撤回）→ 看板（含交接摘要）→ 失败重来。原型当前缺派活输入框（FR-10）与任务看板标签（FR-11）。
